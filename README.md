# ERP Supermarche

Ce projet est composé d'un frontend et d'un backend.

## Structure du projet

- `/frontend` : Application frontend (React + Vite)
- `/backend` : Application backend (Java Spring Boot)

## Lancement

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
# Instructions pour le backend (ex: ./mvnw spring-boot:run)
```
